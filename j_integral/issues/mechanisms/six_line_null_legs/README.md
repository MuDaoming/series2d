# 六传播子：两条无质量外腿分别给出额外退化

取 e6 sector `1111101`，独立输入写为

$$
D_1=L_1^2,\ D_2=(L_1+p)^2,\ D_3=L_2^2,\
D_4=(L_2+k)^2,\ D_5=(L_2+q)^2,\
D_6=(L_1+L_2+r)^2.
$$

branch 为 $\{1,2\},\{3,4,5\},\{6\}$。原始条件是 $p^2=k^2=0$，分别来自原 e6 的 $p_3,p_5$。保持所有其它不变量不变，逐一离壳：

| 条件 | Blade 顶层 FI 数 | 顶层普通 J 数 |
| --- | ---: | ---: |
| $p^2=2/7,k^2=3/11$ | 7 | 7 |
| $p^2=2/7,k^2=0$ | 6 | 7 |
| $p^2=k^2=0$ | 2 | 4 |

所有条件下均只有恒等传播子置换自对称。J 计算保留低 sector/边界，离壳条件下 dot<=1 目标不足以闭合，因此实际保存的离壳输入增加到 dot<=2，DE 闭合；数目又在另一个质数和 t 点稳定复现。

$L_1$ 的三角子圈在 $p^2=0$ 时具有精确的 bubble 差商表达式，见 [五传播子三角例子](../massless_triangle/README.md)。$k^2=0$ 同样使相邻两条单位指标传播子的参数多项式缺少 $k^2xy$ 项。受控计数进一步将两个条件各自的影响分开：

- k 无质量而 p 离壳，FI 减 1、J 不变；
- 再令 p 无质量，FI 减 4、J 减 3，差额再增加 1。

这确认了该原 sector 的两个 J-FI 差额随两个无质量外腿条件出现，而不是未发现的离散传播子置换。这里仍没有逐条给出所有 FI 约化系数，故“来源已定位”和“所有新增关系已完整解析证明”应区分。

同类原 e6 sector：

- `1111101`、`1111110`：branch 大小 2+3+1，相关无质量外腿为 p3、p5，原计数 J4/FI2。
- `0111111`、`1011111`：branch 大小 1+3+2，相关无质量外腿为 p4、p5，原计数 J3/FI2。

第二组可通过交换哪一个 branch 被积掉来理解不同的 J 计数；它不是声称这四个原 sector 的数值运动学相同。对同一个独立第一组家族的六种 branch 排列，已明确得到 J4、J3、J2 的差异，详见 [branch 选择](../branch_choice/README.md)。
