# 四传播子：完整 bubble 的传播子交换关系

采用之前独立定义的 e6 sector `0110101`，局部编号为

$$
D_1=L_1^2,\quad D_2=L_2^2,\quad
D_3=(L_2+Q)^2,\quad D_4=(L_1+L_2+P)^2.
$$

各传播子都有 $+i0$，branch 为 $\{1\},\{2,3\},\{4\}$。固定 $L_2$ 后，$L_1$ 是 bubble。其一般指标解析式对两指标对称：

$$
\mathcal B_{ab}(K^2)=(-1)^{a+b}(-K^2-i0)^{h-a-b}
\frac{\Gamma(a+b-h)\Gamma(h-a)\Gamma(h-b)}
{\Gamma(a)\Gamma(b)\Gamma(2h-a-b)},\quad h=d/2.
$$

因此完整积分严格满足

$$
I_{a,b,c,e}=I_{e,b,c,a},\qquad I_{2111}=I_{1112}.
$$

这与剩余圈的运动学无关。固定 t 的切片不保留这次交换：交换 $X_1,X_3$ 后

$$
t'=\frac{z}{z+(1-z)(1-t)},\qquad z'=(1-z)t,
$$

故 t、z 混合，不能推出 $J_{2111}(t)=J_{1112}(t)$。

做受控质量拆分，将 $D_1$ 改为 $L_1^2-2/7$，其余不变：

| 条件 | 独立 Blade 顶层 FI 数 | 原 tz 坐标下顶层 J 数 |
| --- | ---: | ---: |
| 两条单传播子 branch 质量都为零 | 2 | 3 |
| 仅 D1 质量平方为 2/7 | 3 | 3 |

后一种情况不再存在同一家族内的 bubble 指标交换等式。这个对照支持原来一个差额由上述交换解释；质量改变也改变多项式，因此不将数值对照冒充唯一性的普适证明。

e6 中同类型的四个 sector 为 `0110101`、`0110110`、`1010101`、`1010110`。它们都有两条单传播子 massless branch，bubble 公式给出同一机制，不只是观察到了相同的数字。

若改成积掉双传播子 branch，两个单传播子 branch 留在 t 两侧，还会有更直接的点态比例关系，见 [branch 选择](../branch_choice/README.md)。
