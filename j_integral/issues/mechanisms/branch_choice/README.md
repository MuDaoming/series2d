# 同一个 FI 家族，哪个 branch 积掉会改变 J 主积分数

这不是新的 FI 恒等式来源，而是决定某些 FI 关系是否能在 J 层使用的具体原因。整个测试保持传播子、质量、运动学、维数不变，只重排三个 branch 在 $t,z$ 定义中的角色：

$$
X_a=(1-z)t,\quad X_b=(1-z)(1-t),\quad X_c=z.
$$

## 六传播子的实际结果

采用 `six_line_null_legs/both_null` 的同一个物理家族，原三个 branch 大小为 $2,3,1$。对所有六种排列，顶层 J 数如下（交换 a、b 不改变数目）：

| z 积分对应的原 branch 大小 | 剩下两 branch 的大小 | 顶层普通 J 数 | 顶层 FI 数 |
| --- | --- | ---: | ---: |
| 1 | 2、3 | 4 | 2 |
| 2 | 1、3 | 3 | 2 |
| 3 | 2、1 | 2 | 2 |

所有输入都含各三-branch 低 sector 的 dot<=2 目标，DE 均闭合。各排列的顶层 J 数在另一质数和 t 点复核不变。这里是独立六传播子家族的计数，不是声称原完整七传播子 e6 的全局 J 数已经从 79 改成某个新值。

## 明确的点态约化为什么随排列变化

对普通正整数指标 $\nu$，把 branch b 内所有加 dot 的对象按 $\nu_i$ 加权求和。由于 branch 内 Feynman 参数之和为 1，FBI 归一化给出一个公共因子，剩下的权重正比于 $X_b$。所以任何两条未积掉的 branch a、b 都有精确点态恒等式

$$
\boxed{(1-t)\sum_{i\in a}\nu_iJ_{\nu+e_i}(t)
=t\sum_{j\in b}\nu_jJ_{\nu+e_j}(t).}
$$

此处 $e_i$ 表示只将第 i 个指标加一。对于被积掉的 branch c，类似权重是 $z$，而不是与另两者成 t 有理比例的 $1-z$；不能同样从积分号内提出。

六传播子原坐标的 a、b 为 $\{1,2\},\{3,4,5\}$，因此

$$
(1-t)(J_{211111}+J_{121111})
=t(J_{112111}+J_{111211}+J_{111121}).
$$

若改成积掉 $\{3,4,5\}$，未积掉的 a、b 为 $\{1,2\},\{6\}$，则变成

$$
(1-t)(J_{211111}+J_{121111})=tJ_{111112}.
$$

所以改变投影改变了可在固定 t 下直接使用的 dot 组合关系。这条一般恒等式本身不能单独证明表中每一个主积分数，但它给出了不同 J 问题拥有不同点态关系的具体来源；数目则由独立 IBP 计算并复核。

`check_branch_dots.py` 已对所有排列检查恒等式在每个主积分和边界函数上的系数均为零。它不把 J 的 t 导数当作代数约化。

## 四传播子的更简单例子

原来的 `0110101` 家族，两条单传播子 branch 分别是 $\{1\},\{4\}$，中间是 $\{2,3\}$。

- 积掉单传播子 branch：顶层 J 3 个。
- 积掉中间的双传播子 branch：顶层 J 2 个。

后一种坐标下直接有

$$
(1-t)J_{2111}=tJ_{1112}.
$$

原来积掉第 4 条传播子的坐标下，$X_1/X_4$ 含 z，没有这条点态比例关系。这具体展示了某些额外 J 来自切片选法，而非原 FI 家族固有的更大复杂度。

将两条单传播子 branch 的质量拆开后，采用新坐标仍是 J 2 个，而 FI 是 3 个。这并不矛盾：J 的约化系数可依赖 t，积掉 t 时不同的有理权重可以产生多个 FI，不能仅从主积分数目推出两个约化问题等价。
