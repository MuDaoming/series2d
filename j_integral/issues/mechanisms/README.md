# 为什么某些 sector 的 J 比 FI 多：具体机制与受控检验

## 目前能说清什么

本研究不是把“存在 t-IBP”当作机制。要说明的是：完整 FI 用了什么具体关系、它为什么不保持固定 t 的切片、改变哪个条件后差额消失。

下面已经有显式推导的包括：完整 bubble 的传播子交换；一般 s 的 sunrise 关系中恰在特殊点消失的加权积分；真空积分的单尺度 IBP；无质量三角子圈的解析差商；无标度边界周期为零。对更大的 box/六传播子，已用受控离壳测试定位到无质量外腿和对应的参数多项式退化，但尚未逐条完成所有新增 FI 关系。

所有计数表均指普通顶层主积分；边界函数另列。独立数值 J 计数/DE 闭合及跨质数稳定是验证证据，不是任意 dot 下完备性的普适证明。

## 1. 完整子圈的传播子交换，改变固定 t 切片

e6 的四传播子 `0110101` 及其三个同类型 sector，在一个圈中只有两条 massless 传播子。这就是可完整积分的 bubble，其 Gamma 函数表达式对两个指标对称，所以 FI 有 $I_{2111}=I_{1112}$。

原来的 tz 选择把这两条传播子分给 X1、X3；交换它们时新的 t 同时依赖旧 t、z，不能得到固定 t 下的相等关系。

受控拆开这两条线的质量后：

| 条件 | FI | J |
| --- | ---: | ---: |
| 保留交换对称 | 2 | 3 |
| 破坏交换对称 | 3 | 3 |

完整 bubble 解析式、交换后的坐标和独立计数见 [四传播子例子](four_line_exchange/README.md)。

## 2. 特殊运动学让完整积分中的额外项消失

### 2a. 首个 sunrise 例子的解释需要补充这一点

等质量传播子置换在任何 s 下都存在，但一般 s 时 FI2/J2，并没有差额。因此此前只说传播子置换，解释不完整。

令 $\sigma=s/m^2$。一般 s 下有精确关系

$$
I_{112}=\frac{3d-8}{8m^2}I_{111}
-\frac{(d-2)^2}{16(d-3)m^4}T^2
+\frac{\sigma-1}{2}\int_0^1t(1-t)J_{121}(t;s)dt.
$$

只有 $\sigma=1$ 时最后一项消失，得到 FI1/J2。多项式在该点也分解为

$$
F=m^2(\alpha_1+\alpha_2)(\alpha_1+\alpha_3)(\alpha_2+\alpha_3).
$$

所以这个具体例子是“完整积分置换关系 + 特殊运动学消掉剩余加权积分”共同作用，不是仅凭有置换就必然 J>FI。

一般维度、一般 s 的精确 z-IBP 及独立数值核对见 [sunrise 变形](sunrise_deformation/README.md)。

### 2b. 无质量外腿使子圈参数多项式退化

在 e6 五传播子 `1110101` 中，一个 massless 三角子圈有一条外腿 $p^2=0$。它的参数多项式少掉了 $p^2xy$ 项，完整子圈变成两个 bubble 的差商：

$$
\mathcal T(0,A,B)=-\frac{2(d-3)}{d-4}
\frac{\mathcal B(A)-\mathcal B(B)}{A-B}.
$$

相应的参数向量场可明确写成 $V=B\partial_x-A\partial_y$。在 $F=c(Ax+By)+\eta xy$ 中，$VF=\eta(By-Ax)$，$\eta\propto p^2$。当 p 无质量时这个 F 求导项消失，IBP 更简单；但

$$
t=\frac{x+y}{x+y+b},\qquad Vt=\frac{b(B-A)}{(x+y+b)^2}\ne0.
$$

所以这个关系改变切片，固定 t 的 delta 约束会产生 t 导数，不能直接用于 J 的代数约化。

保持拓扑、其它不变量不变，独立测试如下：

| 家族/条件 | FI | J |
| --- | ---: | ---: |
| 五传播子 2+2+1，p 离壳 | 7 | 5 |
| 同一例子，p 无质量 | 2 | 3 |
| 五传播子 1+3+1，相关外腿离壳 | 2 | 3 |
| 同一例子，相关外腿无质量 | 1 | 3 |
| 六传播子，两条相关外腿都离壳 | 7 | 7 |
| 同一例子，只留一条无质量 | 6 | 7 |
| 同一例子，两条都无质量 | 2 | 4 |

2+2+1 例子和六传播子例子均没有非平凡的传播子置换自对称，不能用“漏掉传播子交换”来解释。

三角子圈的公式已完整推导并数值核验；box 子圈也存在相同的缺项与参数向量场结构。不过，本次没有把后三种条件下所有额外 FI 关系逐条解析列出。因此这些测试将机制定位到具体的外腿/多项式退化，并不等于整套 FI 约化已完成。

详见 [三角子圈](massless_triangle/README.md)、[bubble-box](bubble_box/README.md)、[六传播子](six_line_null_legs/README.md)。

## 3. 完整真空积分的齐次性与动量 IBP，将顶层约化到低 sector

DP 中有质量为 $(m,0,m)$、外动量平方为零的三传播子 family。它的 J 有一个普通顶层主积分，但 FI 顶层没有主积分。不是 FI 为零，而是

$$
\boxed{I_{111}=\frac{d-2}{2(d-3)m^2}T^2.}
$$

可以不使用传播子置换地推导：

$$
0=(d-3)I_{111}-2m^2(I_{211}+I_{112})+TT_2,
$$

$$
m^2(I_{211}+I_{112})=(d-3)I_{111},\quad
T_2=\frac{d-2}{2m^2}T.
$$

也能直接解析完成两个参数积分。在 Cheng-Wu 规范中，$U=u(1-u)+x,F=m^2U$，一个参数是 $x\in[0,\infty)$，先作初等幂积分即可得到 Gamma/Beta 函数。

但固定 t 相当于 $t=u/(u+x)$，会约束 x、u 的比例，不能再独立积掉 x。J111 是非零的 Appell 函数，完整积分后才只需低 sector。这是一个明确的“整个顶层消失”机制，而非离散交换减少一个 dot。

推导、解析 J、独立 Blade/J 验证见 [真空例子](vacuum_m0m/README.md)。它覆盖 DP 的四个等价三传播子 sector；不能把这四个代表位置误算成四次不同机制。

## 4. 无标度子圈：非零边界函数的完整周期为零

e6 四传播子例子的边界函数为

$$
B(t)=C_Bt^{-h}(1-t)^{h-3},\quad h=d/2.
$$

它非零，但按维数/端点解析正规化，

$$
\int_0^1B(t)dt=C_B\frac{\Gamma(1-h)\Gamma(h-2)}{\Gamma(-1)}=0.
$$

边界解耦出的一个圈是无质量单传播子圈，没有尺度；固定 t 则限制相对参数尺度，故切片不能提前设为零。这个机制解释边界 J 本身为什么不对应独立 FI 周期，不用于替代普通顶层差额的解释。

$\int B=0$ 不表示可从 DE 删除 B，因为 $\int R(t)B$ 一般不为零。端点没有普通收敛带，零必须按解析正规化理解。见 [无标度边界](boundary_scaleless.md)。

## 5. 哪个 branch 被积掉，决定额外 J 是否必须保留

这不是新的 FI 恒等式，而是上述完整积分关系有多少已能在 J 层使用的问题。

同一个六传播子家族，FI 恒为 2；只换 tz 中哪个 branch 对应 z：

| 积掉的 branch 大小 | 顶层 J 数 |
| --- | ---: |
| 1 | 4 |
| 2 | 3 |
| 3 | 2 |

这不是纯粹数字现象。对未积掉的 a、b 两个 branch，有精确点态关系

$$
(1-t)\sum_{i\in a}\nu_iJ_{\nu+e_i}
=t\sum_{j\in b}\nu_jJ_{\nu+e_j}.
$$

因为两组加 dot 的参数权重之比为 $X_a/X_b=t/(1-t)$，与 z 无关；涉及被积掉的 branch 则没有这个比例关系。更换投影改变哪些 dot 组合可作点态约化。四传播子例子也能从 J3 改成 J2。

恒等式的每个主积分/边界系数均已核验；不同投影的全部 J DE 闭合，数目在第二质数/t 点复核。该一般恒等式不单独证明每一张计数表，但明确展示了不同投影为何具有不同点态约化。

见 [branch 选择](branch_choice/README.md)。

## 对原 e6 的 14 个增多 sector 已理解到什么程度

| 原 sector | FI/J | 具体结构与已确认来源 |
| --- | --- | --- |
| 0110101、0110110、1010101、1010110 | 2/3 | 单圈 bubble 的完整传播子交换；质量拆分对照；换投影 J 可为 2 |
| 0111101、0111110、1011101、1011110 | 1/3 | 同一 bubble 交换，加 p5 无质量；去掉后者 FI1→2、J不变 |
| 1110101、1110110 | 2/3 | p3 无质量的三角子圈；无置换自对称；显式差商和改变 t 的参数 IBP |
| 0111111、1011111 | 2/3 | p4、p5 无质量；与 2+3+1 类型不同的 branch 投影；尚未逐条解析全部 FI 关系 |
| 1111101、1111110 | 2/4 | p3、p5 无质量；双离壳/单离壳受控测试；换投影 J 可为 2 |

这里的原 sector 数目来自已有完整 e6 数据。每类选代表独立测试，不声称将同类 sector 的不同数值运动学混同。14 个 sector 已有结构上的对应解释，但不是 14 套完整 FI 约化证书。复杂 DP sector 仍未逐个完成同等级的分类。
