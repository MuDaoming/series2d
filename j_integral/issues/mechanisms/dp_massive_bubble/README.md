# DP 有质量 bubble：一个不依赖无质量外腿的纯交换机制

## 从原 sector 定义

原 DP sector `01110001` 是 D2、D3、D4、D8。平移 $L_1=\ell_1-p_2,L_2=\ell_2$，令 $P=p_1+p_2,Q=p_4$，局部编号为

$$
D_1=(L_1+P)^2-m^2,\quad D_2=L_1^2-m^2,\quad
D_3=L_2^2-m^2,\quad D_4=(L_1+L_2+Q)^2-m^2,
$$

所有传播子有 $+i0$，$m^2=P^2=Q^2=1,P\cdot Q=5/24$。branch 大小为 2+1+1，原 t 位于 branch 0、1 之间，积掉 branch 2。

独立计算得到普通顶层 J 四个

$$
J_{1111},\quad J_{1112},\quad J_{1121},\quad J_{1211},
$$

而完整 FI 仅三个顶层主积分。

## 具体多用的关系

固定 $L_1$，$L_2$ 是质量相等的 bubble，外动量 $K=L_1+Q$。其参数表达式

$$
\mathcal B_{ab}(K^2;m,m)=
\frac{(-1)^{a+b}\Gamma(a+b-h)}{\Gamma(a)\Gamma(b)}
\int_0^1dy\,y^{a-1}(1-y)^{b-1}
[m^2-K^2y(1-y)-i0]^{h-a-b}
$$

在 $y\mapsto1-y$ 下直接给出 $\mathcal B_{ab}=\mathcal B_{ba}$，所以

$$
\boxed{I_{1121}=I_{1112}.}
$$

这就把上面的两个 bubble-dot FI 合并为一个。固定 t 时，交换的是 branch 1、2，即 X2、X3，会混合 t、z；不能得到 $J_{1121}(t)=J_{1112}(t)$。两个 bubble-dot J 在当前约化中各自独立。

此证明不依赖特殊的无质量外腿，也没有假定 $s=m^2$ 的 sunrise 退化条件。它是原先“完整积分可以交换传播子，切片不能”的一个直接有质量实例。

## 受控破坏对称

只将 D3 的质量平方改为 5/4，其他条件不变。独立 Blade maximal-cut/J 计算：

| bubble 两质量平方 | FI顶层数 | J顶层数 |
| --- | ---: | ---: |
| 1、1 | 3 | 4 |
| 5/4、1 | 4 | 4 |

后一种情况对称变换会同时交换不同质量，故不再是同一指定家族内的指标交换关系。增加的 FI 主积分正是原来 bubble-dot 方向之一。

输入包括三-branch 子 sector 及 dot<=2，J 的完整 DE 闭合。J 数目在第二质数/t 点复核。另一个原 DP sector `01110010` 也有同样的 2+1+1 等质量 bubble 结构和 FI3/J4 计数，以上积分等式不依赖剩余圈的具体不变量而同样适用。
