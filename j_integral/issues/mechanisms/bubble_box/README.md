# 五传播子 1+3+1：传播子交换与无质量外腿同时出现

e6 sector `0111101` 可写为

$$
D_1=L_1^2,\quad D_2=L_2^2,\quad D_3=(L_2+k)^2,\quad
D_4=(L_2+q)^2,\quad D_5=(L_1+L_2+r)^2.
$$

branch 为 $\{1\},\{2,3,4\},\{5\}$，原来的 $k=p_5$ 满足 $k^2=0$。固定 $L_2$ 积掉 bubble，剩下一个单圈 box，其中一条传播子的指标为 $2-d/2$（原 corner 情况），其它三条为单位指标。

外圈 bubble 始终给出 $I_{21111}=I_{11112}$ 的完整积分交换关系。另做 k 的离壳对照，所有其它不变量保持不变：

| 条件 | 顶层 FI 数 | 顶层普通 J 数 |
| --- | ---: | ---: |
| $k^2=0$ | 1 | 3 |
| $k^2=2/7$ | 2 | 3 |

两种情况下 bubble 交换关系都仍存在；所以在相同交换机制外，$k^2=0$ 又让 FI 减少一个，而当前 J 数不变。这不能再解释为新增传播子交换。

在 box 参数中，相邻两条单位指标传播子的外腿无质量，F 中缺少对应的 $k^2xy$ 项。若写为 $F=A(\beta)x+B(\beta)y+C(\beta)$，则 $V=B\partial_x-A\partial_y$ 保持 F，却通常改变固定 t 的切片。具体结构和核验见 [无质量子圈](../massless_triangle/README.md)。

这里已经定位了第二个差额的运动学来源和相应子圈参数 IBP 结构；尚未把这个 box 的全部 FI 约化系数一般地解析列出。不能只凭计数对照声称完整解析约化已经完成。

同类 e6 sector 为 `0111101`、`0111110`、`1011101`、`1011110`，四者都有上述 bubble 交换以及 branch 中的 p5 无质量外腿。
