# e6：在J层用有限点AB分子模限制候选，并保留Hermite

## 结论

**已得到一个正确性通过、能缩小全局补充系统的实验方案；目前尚未比原生产算法更快，因此没有替换生产程序。**

按用户确认的含义，只要求有限奇点整数支从 $\mu=0$ 开始，不允许负整数幂；保留非整数支，未施加无穷远区域条件。直接调用既有AB包构造分子模，再把允许分子的Hermite像作为全局关系的表示空间。不是先求出J的DE，也不是重新做t有理重构。

前期三份总结分别是 [J/FI差额机制](../mechanisms/SUMMARY.md)、[e6/DP规模比较](../../tests/IBP_SIZE_SUMMARY.md)、[当前J算法](../../src/IBP/docs/algorithm.md)。新方案的数学定义见 [proposal.md](docs/proposal.md)。

## 具体怎样接入

1. 固定 $t,d$ 及运动学，用现有通用FBI递推取得42维FBI连接 $\partial_zH=A_zH$ 和各个物理密度 $G_\nu=r_\nu H$。这一步不需要J约化。
2. 给定候选分母及分子次数，调用原AB包的 `BootstrapSpec.from_inputs`、`build_reduction_ansatz`，用模的生成元参数化允许分子。分母范围来自上述FBI有理行，并覆盖原Hermite共振原函数，不使用最终J约化系数来决定空间。
3. z=0使用原FBI定义已有的物理局部条件：消失阶数、无log及角点等价。将这个物理解析支交给原AB的 `annihilator_module`，其它有限因子沿用原包构造，再由原包 `impose_caps` 处理次数界。
4. 用现有Hermite核处理这些允许分子，选其像的线性基。全局关系就在这个较小空间内表达；保留原算法的42个共振全导数种子和端点贡献。
5. 将1111个物理J目标约化到原来的固定主对象列表，与原算法逐系数核对。主对象列表只用于最后验证，不参与AB分子模的构造。

没有修改 `j_integral/src/IBP` 的算法，也没有修改AB包。新增代码是研究用的数据转换、原API调用及Hermite像空间映射。C++直接包含并复用生产源码中的FBI、端点、Hermite和稀疏线性代数实现；没有另写一套FBI或AB算法。

## 系统究竟从多少变为多少

以e6原投影，$p=9223372036854775783,t=17,d=26/7$ 为例：

| 项目 | 不加AB、相同分母和次数范围 | 加入物理局部条件的AB模 |
|---|---:|---:|
| 待定分子参数 | 966 | **411** |
| 分子经Hermite后的像空间维数 | 446 | **169** |
| 全局非零补充方程 | 42 | 42 |
| 全局方程实际涉及的坐标列 | 422 | **127** |
| 全局方程独立秩 | 42 | 42 |
| 全局非零系数 | 9450 | **1220** |
| 1111个目标系数与原算法一致 | 是 | 是 |

“966→411”是固定分母和次数界内的有限维参数数目，不是说多项式模本身的秩由966降到411。两个像空间方案使用同一种坐标压缩，因此422→127能区分AB约束的作用与单纯换坐标的作用。

与当前原算法比较，还必须把阶段分清：

| 算法 | 局部物理端点条件 | 全局关系系统 | 说明 |
|---|---|---|---|
| 当前原算法 | 与共振关系一起提交 | 合计94行、54独立、501个出现坐标 | 不是矩形966参数播种 |
| AB像空间实验 | 52行、12独立、13个出现坐标 | 42行、42独立、127个出现坐标 | 先做局部条件，再在AB像空间表达全局关系 |

新方案的非零行总数仍是52+42=94，**没有减少原来的42个共振种子**；减少的是全局坐标数及相应非零系数。两阶段坐标经过变换，不应把13和127简单相加当作原坐标中的不同变量数。169是整个允许像空间的维数，127是实际出现在全局关系里的坐标数，两者也不能混称。

只把411个AB组合直接作为原函数种子交给Hermite，而不缩小表示空间时，仍得到原来的94行/501坐标；这一直接接法没有改善最终系统。因此实际有效的步骤是用模约束后的Hermite像进行表示。

AB条件也不等价于“恰好对应FI”：允许像空间比1111个物理目标所需的79维J空间仍大。该必要条件的作用已经验证，但没有得到任意被积函数是否对应FI的充要判据。

## 验证范围

| 例子 | 质数 | t | 分子参数：原始→AB | 像空间：原始→AB | 全局出现列：原始→AB | J主对象 |
|---|---:|---:|---:|---:|---:|---:|
| 原e6投影 | 9223372036854775783 | 17 | 966→411 | 446→169 | 422→127 | 79 |
| 同一投影第二点 | 1000003 | 23 | 966→411 | 446→169 | 422→127 | 79 |
| e6分离投影 | 9223372036854775783 | 17 | 946→394 | 433→157 | 409→115 | 61 |

三例都处理完整1111个三branch、无分子、dot≤2目标，主对象保持独立、全部目标张成、所有约化系数与原算法逐项相同，无缺失关系。第一例的实验基线也与此前保存的公共J接口结果逐项相同。局部AB截断余量从4增加到16后，第一例的411个AB基向量逐项不变。

这些是有限域数值验证与显式截断结果，不是任意维数/指标下完备性的证明。没有测试DP，也没有引入无穷远区域约束。完整结果见 [results](results)，单点约化矩阵以gzip保存。

## 不能省略的局部解问题

直接用FBI形式DE的所有Taylor解构造模，会将1111个真实目标中的96个排除：同一966参数范围得到395参数空间，但这不是物理允许空间。首个反例 `J{1,1,1,0,2,0,1}` 在z=0的形式解析解上出现 $z^{-1}$ 项。

单纯除掉各主对象显式的 $z^{N_3-1}$ 也不足以修复，仍排除96个。原FBI轮廓还满足消失阶数、无log和角点等价等局部条件；将这些已有条件纳入后，相关物理整数支只剩一个自由端点常数，96个目标全部重新进入允许空间，参数数目为411。具体反例与截断复核见 [local_condition_checks.json](results/local_condition_checks.json)。

因此不能把这次首次形式系统构造出的395维空间直接用于删物理目标或删种子；这也是保留现有物理端点算法的必要性。

## 性能：当前未提速

原投影第一例在相同实验工具中，原Hermite补充关系及目标约化约1.95秒；AB模构造、基向量组装、成员验证和导出约9.77秒，之后的像空间/Hermite及目标约化约2.91秒。FBI模型构造为共同前处理，约1秒。另一投影也有类似的额外成本。

所以目前是**系统变小，但完整实验链更慢**。模块阶段还包含实验验证、基向量导出等工作，后续可再区分哪些必须留在生产阶段；本轮没有隐去这些成本，也没有据此宣称提速。实验直接调用相同的Hermite核；此耗时不是对生产公共接口的atomic缓存模式作的严格性能回归。

若继续优化，主要目标应是避免先展开全部411个有理行再逐个求像，并复用AB模的结构；不应先删除原来有效的Hermite局部消元。本轮先保留为独立实验，不替换正式后端。

## 复现

从项目根目录运行：

```bash
make -C j_integral/issues/ab_seed_constraints
source j_integral/tests/runtime.sh
python j_integral/issues/ab_seed_constraints/src/run_e6.py --case original63
python j_integral/issues/ab_seed_constraints/src/run_e6.py --case original_small
python j_integral/issues/ab_seed_constraints/src/run_e6.py --case separated63
```

依赖沿用当前FBI/AB/FLINT环境，不打包第三方依赖。`build/` 是可再生的快照、分子基与日志，正式记录在 `results/`。没有使用Slurm或天河。

只复核已保存的两种方案与原算法的全部约化系数，可运行 `python j_integral/issues/ab_seed_constraints/src/verify_saved.py`；仅需Python标准库。原始候选输出以 `*_image_ab.json.gz`、`*_image_trivial.json.gz` 保存，不只保存“通过”标记。
